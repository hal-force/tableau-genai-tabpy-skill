## `scripts/genai_calc.py`

Generate the provider-specific SCRIPT_STR calculation.

```text
usage: genai_calc.py [-h]
                     [--provider {anthropic,asksage,asksage-native,azure-openai,bedrock,bedrock-iam,gateway,openai,palantir,vertex,vertex-sa}]
                     [--mode {demo,keystore}] [--list-providers] [--url URL]
                     [--region REGION] [--project PROJECT]
                     [--location LOCATION] [--host HOST] [--resource RESOURCE]
                     [--token-url TOKEN_URL] [--temperature TEMPERATURE]
                     [--secret-name SECRET_NAME]
                     [--keystore-service KEYSTORE_SERVICE]
                     [--demo-key-from-keystore]
                     [--max-grounding-tokens MAX_GROUNDING_TOKENS]
                     [--max-output-tokens MAX_OUTPUT_TOKENS]
                     [--timeout TIMEOUT] [--tls TLS] [--no-prompts-param]
                     [--empty-message EMPTY_MESSAGE] [--split-hint SPLIT_HINT]
                     [--field-prompts FIELD_PROMPTS]
                     [--field-prompt FIELD_PROMPT]
                     [--field-grounding FIELD_GROUNDING]
                     [--field-model FIELD_MODEL]
                     [--field-token-count FIELD_TOKEN_COUNT] [--out OUT]

Generate the 'Generative AI Response' TabPy calculation for a provider.

Emits a Tableau SCRIPT_STR(...) formula (caption-based field references,
pasteable into Tableau's calc editor or consumed by patch_workbook.py) plus
a reviewable copy of the embedded Python.

  python3 genai_calc.py --provider asksage --mode keystore --out OUT_DIR
  python3 genai_calc.py --provider bedrock --region us-gov-west-1 --mode keystore
  python3 genai_calc.py --provider gateway --url https://.../chat/completions --mode demo
  python3 genai_calc.py --list-providers

Modes
  demo      credential literal inside the calc (placeholder by default; use
            --demo-key-from-keystore to inject the stored key at write time
            without it passing through the LLM). Laptop demos only.
  keystore  no credential in the workbook; resolved on the TabPy host at
            call time (env -> macOS Keychain -> keyring -> secrets file).

SCRIPT_STR arguments (the calc expects these Tableau fields):
  _arg1 [Prompts]                engineered prompt (list parameter)  *
  _arg2 [Grounding]              string parameter set by the parameter action
  _arg3 [Select LLM]             model id parameter
  _arg4 [Grounding Token Count]  INT(LEN([Grounding])/4)
  _arg5 [Prompt]                 free-text analyst question          *
  * with --no-prompts-param, _arg1 is [Prompt] and there is no _arg5.

options:
  -h, --help            show this help message and exit
  --provider {anthropic,asksage,asksage-native,azure-openai,bedrock,bedrock-iam,gateway,openai,palantir,vertex,vertex-sa}
  --mode {demo,keystore}
  --list-providers
  --url URL             override the endpoint URL
  --region REGION       AWS region (bedrock*), e.g. us-east-1, us-gov-west-1
  --project PROJECT     GCP project id (vertex-sa)
  --location LOCATION   Vertex location (default global)
  --host HOST           Foundry hostname (palantir), e.g.
                        acme.palantirfoundry.com
  --resource RESOURCE   Azure OpenAI resource name
  --token-url TOKEN_URL
                        Ask Sage native token URL override
  --temperature TEMPERATURE
                        asksage-native only
  --secret-name SECRET_NAME
                        override the primary secret name (e.g. asksage.prod
                        for a second account)
  --keystore-service KEYSTORE_SERVICE
  --demo-key-from-keystore
                        demo mode: inject the stored secret(s) into the calc
                        at write time. The value is written to disk only,
                        never printed.
  --max-grounding-tokens MAX_GROUNDING_TOKENS
  --max-output-tokens MAX_OUTPUT_TOKENS
  --timeout TIMEOUT
  --tls TLS             verify | insecure | /path/to/ca-bundle.pem
  --no-prompts-param    workbook has no Prompts list parameter; _arg1 =
                        [Prompt]
  --empty-message EMPTY_MESSAGE
  --split-hint SPLIT_HINT
  --field-prompts FIELD_PROMPTS
  --field-prompt FIELD_PROMPT
  --field-grounding FIELD_GROUNDING
  --field-model FIELD_MODEL
  --field-token-count FIELD_TOKEN_COUNT
  --out OUT             output directory
```

## `scripts/set_secret.py`

Store / check / delete a secret without exposing it.

```text
usage: set_secret.py [-h] [--from-dialog | --from-terminal |
                     --from-clipboard | --from-file PATH | --check | --delete]
                     [--keep-clipboard]
                     [--backend {auto,macos-keychain,keyring,file}]
                     name

Store an LLM API key (or other secret) without exposing it to the LLM.

The value is read from a hidden macOS dialog, a no-echo terminal prompt,
the clipboard, or a file -- and written straight into the keystore. This
script never prints the value; it reports only "stored (N chars)".

Usage
-----
  # Claude can launch this for you: a hidden-input macOS dialog pops up,
  # you paste the key, the transcript only ever sees "stored (N chars)".
  python3 set_secret.py asksage

  # In your own terminal (no-echo prompt):
  python3 set_secret.py asksage --from-terminal

  # Copy the key first, then (clipboard is cleared afterwards):
  python3 set_secret.py openai --from-clipboard

  # Multi-line secrets such as a Google service-account JSON:
  python3 set_secret.py vertex.service_account --from-file ~/Downloads/sa.json

  python3 set_secret.py asksage --check     # present/absent + where
  python3 set_secret.py asksage --delete

Zero-dependency alternative (macOS, in your own terminal) -- prompts with
no echo and writes the same Keychain item the TabPy calculation reads:

  security add-generic-password -U -s tableau-genai -a asksage -w

positional arguments:
  name                  secret name, e.g. asksage, openai, bedrock,
                        vertex.service_account, asksage.email

options:
  -h, --help            show this help message and exit
  --from-dialog         hidden-input macOS dialog (default when no TTY on
                        macOS)
  --from-terminal       no-echo terminal prompt (default when a TTY is
                        attached)
  --from-clipboard      read the clipboard, then clear it
  --from-file PATH
  --check               report present/absent only
  --delete
  --keep-clipboard
  --backend {auto,macos-keychain,keyring,file}
                        file = ~/.tableau-genai/secrets.json (chmod 600); use
                        for Linux/Docker TabPy hosts with no OS keystore
```

## `scripts/ca_bundle.py`

Export trusted roots to a CA bundle and probe TLS.

```text
usage: ca_bundle.py [-h] [--out OUT] [--add [ADD ...]] [--test TEST]

Export a CA bundle so the TabPy calc can VERIFY TLS to internal gateways.

Corporate / DoD gateways are often signed by an internal CA that Python's
certifi bundle does not include -- which is why calcs end up with
verify=False. On macOS the trusted roots (including MDM-pushed corporate and
DoD roots) are in the System keychain; export them and point the calc at the
file with genai_calc.py --tls PATH.

  python3 ca_bundle.py [--out ~/.tableau-genai/ca-bundle.pem] [--test URL]
  python3 ca_bundle.py --add dod_roots.pem          # append extra PEM roots (e.g. DoD PKI)

--test makes an unauthenticated GET; any HTTP status (401/403/404) proves the
TLS handshake verified. No credential is sent.

options:
  -h, --help       show this help message and exit
  --out OUT
  --add [ADD ...]  extra PEM files to append
  --test TEST      URL to probe with verification on
```

## `scripts/profile_data.py`

Profile a workbook or its data; detect risks; recommend a Payload.

```text
usage: profile_data.py [-h] [--out OUT] [--max-rows MAX_ROWS]
                       [--grounding-budget GROUNDING_BUDGET]
                       sources [sources ...]

Assess a Tableau workbook and/or its data for GenAI analysis design.

  python3 profile_data.py WORKBOOK.twb[x] [--out DIR]
  python3 profile_data.py DATA.hyper | DATA.csv | DATA.tdsx [--out DIR]

Writes DIR/profile.json and DIR/profile.md:
  * workbook structure: datasources, logical tables, columns (caption <->
    internal name), parameters, worksheets, dashboards, parameter actions
  * existing GenAI scaffold (Generative AI Response / Payload / Grounding /
    token count / Prompt / Select LLM) and risks such as a plaintext API key
    (detected, never printed) or a bloated saved Grounding value
  * per-table column statistics from the Hyper/CSV data (rows, nulls,
    distinct, text length, min/max, short samples) and a role guess
    (id, date, category, title, long_text, url, measure, text)
  * a recommended Payload field list per logical table with a token
    estimate per record and how many records fit the grounding budget

Needs tableauhyperapi for .hyper/.tdsx/.twbx extracts (run with the TabPy
interpreter or any Python that has it).

positional arguments:
  sources

options:
  -h, --help            show this help message and exit
  --out OUT
  --max-rows MAX_ROWS
  --grounding-budget GROUNDING_BUDGET
```

## `scripts/compose_prompts.py`

Render a prompt spec into Prompts parameter members.

```text
usage: compose_prompts.py [-h] [--out OUT] spec

Render prompt-engineering specs into full prompts for the Prompts parameter.

  python3 compose_prompts.py SPEC.json [--out DIR]

SPEC.json
---------
{
  "domain": "DNFSB weekly resident-inspector reports",       # optional context
  "record_noun": "report", "id_label": "Report ID",          # used in shared constraints
  "shared_constraints": ["Use only the GROUNDING DATA ...", ...],   # optional, appended to each
  "free_text_label": "Free text (use the Prompt box)",       # optional; "" to omit
  "prompts": [
    {"label": "Executive Safety Brief",                      # short name
     "summary": "1-page BLUF for leadership",                # brief description (Display As)
     "persona": "...", "audience": "...", "objective": "...",
     "constraints": ["...", "..."],
     "output": "Markdown: BLUF line, then ..."}               # optional output format
  ]
}

Each prompt becomes (the full text is the parameter VALUE):

  PERSONA: ...
  AUDIENCE: ...
  OBJECTIVE: ...
  CONSTRAINTS:
  - ...
  OUTPUT FORMAT: ...

and "<label> - <summary>" is the Display As alias. Double quotes are
converted to single quotes so values are safe as Tableau string literals.
Writes DIR/prompts.json (consumed by patch_workbook.py) and DIR/prompts.md.

positional arguments:
  spec

options:
  -h, --help  show this help message and exit
  --out OUT
```

## `scripts/payload.py`

Build a Payload formula.

```text
usage: payload.py [-h] [--fields [FIELDS ...]] [--type [TYPE ...]]
                  [--max-chars [MAX_CHARS ...]] [--from-profile FROM_PROFILE]
                  [--table TABLE]

Build the row-level Payload calculation (one record of grounding text).

  python3 payload.py --fields "Report ID=Report Id" "Week Ending=Week Ending Date"       "Site" "Title=Report Title" "Report Content=Full Text" [--max-chars "Full Text=6000"]
  python3 payload.py --from-profile profile.json [--table Reports]

FIELD spec is "Label=Field Caption" or just "Field Caption". Types come from
--from-profile (or --type "Caption=date"); non-strings are wrapped in STR().
Prints the caption-based formula (what you'd paste in Tableau). The patcher
imports build_formula() and passes internal names instead.

All fields must come from ONE logical table: a row-level calc that mixes
tables in a relationship model will fail or duplicate rows.

options:
  -h, --help            show this help message and exit
  --fields [FIELDS ...]
  --type [TYPE ...]     "Caption=date|number|string"
  --max-chars [MAX_CHARS ...]
                        "Caption=N" truncates long text
  --from-profile FROM_PROFILE
  --table TABLE
```

## `scripts/patch_workbook.py`

Write the patched .twb/.twbx.

```text
usage: patch_workbook.py [-h] [--prompts PROMPTS] [--payload [PAYLOAD ...]]
                         [--payload-max-chars [PAYLOAD_MAX_CHARS ...]]
                         [--payload-type [PAYLOAD_TYPE ...]]
                         [--models [MODELS ...]]
                         [--prompt-default PROMPT_DEFAULT] [--keep-prompt]
                         [--keep-grounding] [--datasource DATASOURCE]
                         [--out-dir OUT_DIR] [--suffix SUFFIX]
                         [--report REPORT]
                         workbook

Write a new .twb/.twbx with the GenAI calc, Payload, and Prompts parameter.

  python3 patch_workbook.py WORKBOOK.twb[x]       --prompts prompts.json       --payload "Report ID=Report Id" "Week Ending=Week Ending Date" "Site"                 "Title=Report Title" "Report Content=Full Text"       [--payload-max-chars "Full Text=8000"]       [--models "Claude Sonnet 4=claude-sonnet-4-20250514" "GPT-5=gpt-5"]       [--out-dir DIR] [--suffix "GenAI - Gateway"]       -- --provider gateway --mode keystore --url https://... --tls ~/.tableau-genai/ca-bundle.pem

Everything after "--" is passed to genai_calc.py (provider, mode, URL ...).

What it changes (the original file is never modified):
  * Generative AI Response -> new SCRIPT_STR body for the provider, args
    (Prompts, Grounding, Select LLM, Grounding Token Count, Prompt)
  * Payload               -> rebuilt from --payload (one logical table)
  * Prompts               -> NEW string list parameter: value = full
    engineered prompt, Display As = short description; added to the
    dashboard next to the Prompt box and to every dependency block
  * Select LLM            -> members replaced when --models is given
  * Grounding             -> saved value reset to "" (--keep-grounding to skip)
  * Prompt                -> default set to --prompt-default (default "")
Every duplicate definition (datasource + worksheet/dashboard dependency
copies) is updated. If the workbook has no GenAI scaffold, the parameters
and calcs are created in --datasource and build steps for the button
sheet + parameter action are printed.

Validation before writing: Python body compiles; every [ref] resolves;
keystore mode leaves no credential literal anywhere in the workbook; the
original calc's embedded key (if any) is gone; output re-parses; zone ids
are unique per layout.

positional arguments:
  workbook

options:
  -h, --help            show this help message and exit
  --prompts PROMPTS     prompts.json from compose_prompts.py
  --payload [PAYLOAD ...]
                        "Label=Field Caption" ... (omit to keep current
                        Payload)
  --payload-max-chars [PAYLOAD_MAX_CHARS ...]
  --payload-type [PAYLOAD_TYPE ...]
  --models [MODELS ...]
                        "Display As=model-id" ... replaces Select LLM members
  --prompt-default PROMPT_DEFAULT
                        default text of the Prompt box (default "")
  --keep-prompt         leave the Prompt box default as is
  --keep-grounding
  --datasource DATASOURCE
                        caption of the data source to use (default: the one
                        with the calc)
  --out-dir OUT_DIR
  --suffix SUFFIX
  --report REPORT       write a JSON change report here
```

## `scripts/server_io.py`

List / download / publish on Tableau Server or Cloud.

```text
usage: server_io.py [-h]
                    {list-workbooks,list-datasources,download-workbook,download-datasource,publish} ...

Tableau Server / Cloud I/O for the GenAI skill (download to profile, publish result).

  python3 server_io.py list-workbooks   [--search TEXT] [--limit 25]
  python3 server_io.py list-datasources [--search TEXT] [--limit 25]
  python3 server_io.py download-workbook   NAME_OR_LUID --out DIR [--no-extract]
  python3 server_io.py download-datasource NAME_OR_LUID --out DIR
  python3 server_io.py publish FILE.twb[x] --project NAME [--name NAME] [--overwrite]

Credentials (never printed), first match wins:
  1. env TABLEAU_SERVER_URL / _SITE / _PAT_NAME / _PAT_SECRET
  2. the tableau-prep-etl skill's store (Keychain service 'tableau-prep-etl',
     accounts url, site, pat-name, pat-secret) -- set up once by that skill
  3. this skill's keystore names server.url / server.site / server.pat_name /
     server.pat_secret (python3 set_secret.py server.pat_secret)

publish refuses any workbook whose GenAI calc embeds a credential (demo
builds). Published workbooks call the TabPy configured on the SERVER
(Analytics Extensions); the keystore lookup then runs on that host -- see
reference/security.md.

positional arguments:
  {list-workbooks,list-datasources,download-workbook,download-datasource,publish}

options:
  -h, --help            show this help message and exit
```
